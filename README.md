# 정책자금 한눈에 보기

소상공인·중소기업 정책자금(소진공·중진공)의 조건을 비교하고, 내게 맞는 자금을 진단하고, 사업계획서 초안과 서류 양식을 내려받는 정적 웹 페이지입니다. 서버와 외부 라이브러리가 없어 `index.html`을 브라우저로 열면 동작하고, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

이 화면의 양식과 초안은 공식 서식이 아니며 개인이 정리한 신청 준비용 자료입니다. 자금 정보는 소진공 제2026-576호, 중진공 제2026-574호(2026.10.1) 공고 기준이고, 진단·서류 체크리스트는 이전 정리본 기준의 1차 점검입니다. 신청 전에 공고 원문을 확인하세요.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html`, `styles.css` | 마크업과 스타일 |
| `core.js`, `detail.js`, `list-view.js`, `finder-view.js`, `draft-view.js`, `docs-view.js`, `app.js` | 화면 스크립트 (이 순서로 불러옴) |
| `lib/` | 자격 진단 규칙, 초안 작성, .docx 생성기 |
| `data/funds.js` | 자금 데이터(생성물) |
| `forms/` | 내려받는 양식 파일 |
| `fonts/` | Pretendard 서브셋과 라이선스(SIL OFL 1.1) |

## 원본

데이터 정본(CSV), 데이터를 만드는 도구, 양식 생성기, 테스트, 상세 설명은 이 저장소의 `source` 브랜치에 있습니다. `main`(배포용)은 화면 실행에 필요한 파일만 담고 있으며, `source`가 바뀌면 같은 파일을 `main`에 다시 복사합니다.
